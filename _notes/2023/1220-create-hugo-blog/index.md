## はじめに

はてなブログからの移行先をずっと探していて、Hugo と Cloudflare Pages でブログを構築中です。
この記事も Hugo で書いています。

この記事では選定理由や感想などを書きます。

<!--more-->

## Hugo の選定理由

https://gohugo.io/

- Markdown で書きたい
- SaaS はブログサービス終了に手間がかかる

あたりが主な選定理由になります。

JavaScript ベースのライブラリ（Gatsby など）も考えましたが、しばらく更新しない間にパッケージ依存周りでデプロイできなくなったりと管理が大変になりそうだったので、シンプルな SSG を探していました（メインでやりたいことはブログを書くことですし）。 
色々調べていく中で、シンプルに Markdown で書けつつ、ある程度のカスタマイズもできそうだったので Hugo を選びました。

また、基本的な Go 言語は書けるので、Go Template ライクにテンプレートをいじることができるのも体験がよかったです。

## Cloudflare Pages の選定理由

https://pages.cloudflare.com/

正直 Netlify でもよかったのですが、Cloudflare を触っておきたい気持ちで Cloudflare を選びました。

Hugo のビルドができて、また無料枠が充実しているのもいいですね。

## 記事体験

ブログは、記事内容含め1つのリポジトリで管理しています（private repositoryです）。

記事を書いたらローカル環境で Hugo を立ち上げてプレビューし、問題なければ commit。 
GitHub への push をトリガーとして、Cloudflare Pages でビルド＆デプロイ。

とてもスマートで楽です。

## おわりに

同様の手法でブログを構築する記事もあり、結構よくある手法なのかなと思っています。

今のところこの管理方法で満足しているので、久々にゆるくブログ再開しようと思います。
